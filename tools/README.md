## 写作要点（给人和 agent）
- 写**意图与理由**，不是只贴 dotfile。
- **验证**步骤必须是可直接执行的命令。
- 版本约束明确：`>=x` / `pin x.y.z` / `latest`。
- 平台差异尽量交给 agent，除非有必须记录的坑（那就写进 `platforms/`）。
